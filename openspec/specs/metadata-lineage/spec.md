## Purpose

定义表结构自动同步、字段字典维护与数据血缘能力，为任务配置与数据治理提供元数据支撑；血缘按转换路径分级：向导/LLM 路径提供字段级（多步流水线按节点逐跳记录），手写 Python 路径仅提供表级。

## Requirements

### Requirement: 表结构自动同步
系统 SHALL 自动同步数据源表结构；对 REST/API 数据源，依据返回样例推断字段结构。

#### Scenario: 同步关系库表结构
- **WHEN** 关系库数据源连接建立或刷新元数据
- **THEN** 系统拉取并保存库、表与字段结构信息

#### Scenario: 从 API 样例推断字段结构
- **WHEN** 对 REST/API 数据源刷新元数据且存在返回样例
- **THEN** 系统依据样例推断字段名称与类型结构并保存，供字段选择与字典使用

### Requirement: 字段字典
系统 SHALL 维护字段字典。

#### Scenario: 查询字段字典
- **WHEN** 用户查询字段字典
- **THEN** 系统展示字段定义与说明

### Requirement: 向导与 LLM 路径字段级血缘
系统 SHALL 在向导/LLM 路径的任务配置阶段，基于字段映射静态推导源表字段到目标表字段的血缘关系并保存；当任务以多步流水线表达时，系统 SHALL 按节点逐跳推导并保存每一步的字段来源与去向，使最终目标字段可追溯其经过的中间节点与原始源字段；多源合并节点的结果字段 SHALL 记录其全部上游来源。

#### Scenario: 推导字段级血缘
- **WHEN** 向导或 LLM 路径的任务配置完成
- **THEN** 系统基于字段映射静态推导并保存源表.字段 → 目标表.字段的血缘关系

#### Scenario: 多步链路逐跳可追溯
- **WHEN** 任务的字段经过多个处理节点后写入目标
- **THEN** 系统保存每一步的字段来源与去向，血缘视图可沿链路回溯到原始源字段

#### Scenario: 多源合并血缘
- **WHEN** 目标字段来自合并节点且该节点有多个上游源
- **THEN** 系统记录该字段的全部上游来源，血缘视图中体现多对一关系

#### Scenario: 旧配置等价血缘
- **WHEN** 任务为仅含字段规则的既有配置
- **THEN** 系统按等价编译后的三节点流水线推导血缘，结果与原字段级血缘一致

### Requirement: 手写路径表级血缘
系统 SHALL 对手写 Python 路径的任务，依据任务声明的源与目标连接维护表级血缘；字段级血缘标记为不支持，不在界面伪造字段关系。

#### Scenario: 手写任务仅记录表级血缘
- **WHEN** 手写 Python 任务保存
- **THEN** 系统保存其声明的源表到目标表血缘，并在血缘视图中明确标识字段级血缘不可用
