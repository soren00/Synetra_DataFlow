## Purpose

定义表结构自动同步、字段字典维护与数据血缘能力，为任务配置与数据治理提供元数据支撑；血缘按转换路径分级：向导/LLM 路径提供字段级，手写 Python 路径仅提供表级。

## Requirements

### Requirement: 表结构自动同步
系统 SHALL 自动同步数据源表结构；对 REST/API 数据源，依据返回样例推断字段结构。

#### Scenario: 同步关系库表结构
- **WHEN** 关系库数据源连接建立或刷新元数据
- **THEN** 系统拉取并保存库、表与字段结构信息

#### Scenario: 从 API 样例推断字段结构
- **WHEN** 对 REST/API 数据源刷新元数据且存在返回样例
- **THEN** 系统依据样例推断字段名称与类型结构并保存，供字段选择与字典使用

### Requirement: 字段字典
系统 SHALL 维护字段字典。

#### Scenario: 查询字段字典
- **WHEN** 用户查询字段字典
- **THEN** 系统展示字段定义与说明

### Requirement: 向导与 LLM 路径字段级血缘
系统 SHALL 在向导/LLM 路径的任务配置阶段，基于字段映射静态推导源表字段到目标表字段的血缘关系并保存。

#### Scenario: 推导字段级血缘
- **WHEN** 向导或 LLM 路径的任务配置完成
- **THEN** 系统基于字段映射静态推导并保存源表.字段 → 目标表.字段的血缘关系

### Requirement: 手写路径表级血缘
系统 SHALL 对手写 Python 路径的任务，依据任务声明的源与目标连接维护表级血缘；字段级血缘标记为不支持，不在界面伪造字段关系。

#### Scenario: 手写任务仅记录表级血缘
- **WHEN** 手写 Python 任务保存
- **THEN** 系统保存其声明的源表到目标表血缘，并在血缘视图中明确标识字段级血缘不可用
