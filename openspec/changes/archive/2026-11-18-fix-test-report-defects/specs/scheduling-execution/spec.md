# Spec Delta

## MODIFIED Requirements

### Requirement: 定时任务管理视图
系统 SHALL 提供定时任务管理视图，列出已配置定时的任务及其 cron、启用状态、上次运行时间与下次运行时间，支持对每个任务的定时启用/停用与查看，并 SHALL 支持在该视图内直接为尚未配置定时的任务创建调度（选择所属项目与任务、录入 cron 后保存）。

#### Scenario: 列举并查看定时任务
- **WHEN** 用户打开定时任务管理视图
- **THEN** 系统列出所有已配置定时的任务，含 cron、启用状态、上次运行、下次运行信息

#### Scenario: 启停定时
- **WHEN** 用户对某定时任务执行停用
- **THEN** 该任务不再按 cron 触发；用户可重新启用，启用后按计划继续触发；状态变更反映在视图中

#### Scenario: 新建调度
- **WHEN** 用户在定时任务管理视图点击「新建」，选择项目与任务并录入合法 cron 后确认
- **THEN** 系统为该任务写入调度配置，列表新增该任务并展示其 cron、启用状态与下次运行时间

#### Scenario: 新建调度时 cron 非法
- **WHEN** 用户新建调度时录入非空但不足 5 段的 cron
- **THEN** 系统拦截提交并给出可读提示，不写入任何调度配置

#### Scenario: 无任务可选时的空态
- **WHEN** 用户打开新建调度且当前没有可配置调度的任务
- **THEN** 系统给出空态说明并引导先创建任务，不出现不可提交的死路
