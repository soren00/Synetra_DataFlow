# Spec Delta

## ADDED Requirements

### Requirement: 界面导航可寻址
系统 SHALL 使 Web 界面的页面切换反映在浏览器地址中，并 SHALL 在刷新或直接访问带页面标识的地址时恢复到该页面；未登录时先要求登录、登录后进入目标页面；页面标识无效时回到默认页面且不报错；用户无权限的页面标识按角色可见性回退到其可访问的默认页面。

#### Scenario: 切页更新地址
- **WHEN** 用户点击侧边栏导航项
- **THEN** 地址中写入该页面对应的标识，页面内容随之切换，且浏览器前进/后退可在此前的页面间切换

#### Scenario: 刷新停留在当前页
- **WHEN** 用户在某页面刷新浏览器
- **THEN** 系统仍停留在该页面，而非回到默认页面

#### Scenario: 深链访问
- **WHEN** 已登录用户直接访问带页面标识的地址
- **THEN** 系统打开对应页面，不受此前浏览历史影响

#### Scenario: 未登录深链
- **WHEN** 未登录用户访问带页面标识的地址
- **THEN** 系统先展示登录页，登录成功后进入该目标页面

#### Scenario: 无效或越权标识
- **WHEN** 用户访问不存在的页面标识，或访问当前角色不可见的页面
- **THEN** 系统回到该角色可访问的默认页面且不报错
