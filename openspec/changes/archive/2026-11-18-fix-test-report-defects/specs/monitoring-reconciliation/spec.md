# Spec Delta

## ADDED Requirements

### Requirement: 主机系统资源采集
系统 SHALL 提供主机 CPU、内存与磁盘占用查询；在采集能力不可用的平台（如不具备 `/proc` 的非 Linux 主机）上，系统 SHALL 以结构化的「不支持」标记与零值返回，SHALL NOT 以服务端错误结束请求。

#### Scenario: 受支持平台采集
- **WHEN** 在具备 `/proc` 的主机上请求主机系统资源
- **THEN** 系统返回 CPU 占用百分比、核数、内存与磁盘的总量/占用/百分比，并标记该平台受支持

#### Scenario: 非 Linux 平台降级
- **WHEN** 在不具备 `/proc` 的主机上请求主机系统资源
- **THEN** 系统正常返回并标记该平台不受支持，资源数值以零值占位

#### Scenario: 降级不牵连其它区域
- **WHEN** 主机系统资源不可用
- **THEN** 监控页其余区域（运行历史、实时日志、对账、告警事件）正常加载，仅资源区展示不可用说明
