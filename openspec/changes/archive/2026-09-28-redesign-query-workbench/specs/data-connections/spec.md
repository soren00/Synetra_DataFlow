## ADDED Requirements

### Requirement: 关系库库表与视图实时枚举

系统 SHALL 对已授权的关系库连接实时枚举目标库的 schema、表与视图，作为只读查询工作台的导航数据来源；枚举 SHALL 直接读取目标库的系统目录，SHALL 不依赖本地已同步的元数据字典（本地字典可能缺失或过期，不可作为导航依据）。

#### Scenario: 枚举 MySQL 连接的表与视图

- **WHEN** 用户选择一个已授权的 MySQL 关系库连接并展开库表视图列表
- **THEN** 系统返回该连接目标库下的表与视图清单，并为每个对象标注其类型为表或视图

#### Scenario: 枚举 PostgreSQL 连接并过滤系统 schema

- **WHEN** 用户选择一个已授权的 PostgreSQL 关系库连接并展开库表视图列表
- **THEN** 系统返回用户 schema 下的表与视图清单，且结果中不包含 `pg_catalog` 与 `information_schema` 等系统 schema 的对象

#### Scenario: 枚举按 schema 收窄

- **WHEN** 连接存在多个用户 schema 且用户指定其中一个 schema 后刷新列表
- **THEN** 系统仅返回该 schema 下的表与视图，并同时给出该连接可选的 schema 清单

#### Scenario: 拒绝越权枚举

- **WHEN** 请求方所属项目与连接所属项目不一致时发起库表枚举
- **THEN** 系统拒绝该请求并返回无该项目访问权限，不返回任何对象清单

#### Scenario: 枚举仅执行只读系统目录查询

- **WHEN** 用户枚举库表与视图
- **THEN** 系统不向目标库发送任何写入、DDL 或其他 DML 语句

### Requirement: 查询工作台四区布局

系统 SHALL 在只读查询页以四区布局呈现关系库查询能力：左列上方为数据连接选择器，左列下方为当前连接的表与视图列表，右列上方为 SQL 编辑器与执行操作，右列下方为查询结果预览区。

#### Scenario: 左列选择连接并查看库表

- **WHEN** 用户打开只读查询页
- **THEN** 左列上方展示可选择的数据连接，左列下方展示当前所选连接的表与视图列表

#### Scenario: 切换连接刷新库表列表

- **WHEN** 用户在左列切换为另一个关系库连接
- **THEN** 左列下方的表与视图列表刷新为该连接的对象清单，不再展示前一连接的对象

#### Scenario: 未选择连接时的引导

- **WHEN** 用户尚未选择数据连接或系统无可用的关系库连接
- **THEN** 系统在库表视图列表区给出明确提示，且不发起枚举请求

#### Scenario: 查询结果在右下方预览区呈现

- **WHEN** 用户在右上方 SQL 编辑器提交查询并执行成功
- **THEN** 右下方结果预览区以列名表头与按列顺序对应的真实值渲染结果行

### Requirement: 点击表名预填只读查询语句

系统 SHALL 在用户点击表与视图列表中的任一对象时，向 SQL 编辑器写入一条针对该对象的基础只读查询语句；该语句 SHALL 使用 schema 限定的对象名并包含行数上限；系统 SHALL 仅预填而不自动执行查询。

#### Scenario: 点击表名生成基础查询语句

- **WHEN** 用户点击列表中的表 `orders`
- **THEN** SQL 编辑器的内容被替换为一条以限定标识符引用 `orders` 且带行数上限的 `SELECT` 语句

#### Scenario: 点击表名不触发查询执行

- **WHEN** 用户点击列表中的表名或视图名
- **THEN** 系统不向查询接口发起请求，仅更新 SQL 编辑器内容

#### Scenario: 预填后由用户改写并执行

- **WHEN** 用户在预填语句基础上增加 `WHERE` 条件后点击执行
- **THEN** 系统按既有只读守卫（单条 SELECT、拒绝写与多语句、行数上限与超时）执行该语句并返回结果

#### Scenario: 标识符按目标库方言安全引用

- **WHEN** 被点击对象的名称包含大写字母或特殊字符
- **THEN** 系统按该连接所属数据库的方言对该标识符做引用，生成的语句可直接执行

### Requirement: 库表视图列表的检索与类型过滤

系统 SHALL 支持按名称关键字过滤表与视图列表，并 SHALL 支持在「表」与「视图」之间切换显示范围。

#### Scenario: 关键字过滤列表

- **WHEN** 用户在列表上方的检索框输入关键字
- **THEN** 列表仅展示名称包含该关键字的表与视图

#### Scenario: 按对象类型过滤

- **WHEN** 用户将对象类型切换为仅表或仅视图
- **THEN** 列表仅展示所选类型的对象，切换回全部时恢复展示两类对象
