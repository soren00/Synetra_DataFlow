# Spec Delta

## MODIFIED Requirements

### Requirement: 向导与 LLM 路径字段级血缘
系统 SHALL 在向导/LLM 路径的任务配置阶段，基于字段映射静态推导源表字段到目标表字段的血缘关系并保存；当任务以多步流水线表达时，系统 SHALL 按节点逐跳推导并保存每一步的字段来源与去向，使最终目标字段可追溯其经过的中间节点与原始源字段；多源合并节点的结果字段 SHALL 记录其全部上游来源。

#### Scenario: 推导字段级血缘
- **WHEN** 向导或 LLM 路径的任务配置完成
- **THEN** 系统基于字段映射静态推导并保存源表.字段 → 目标表.字段的血缘关系

#### Scenario: 多步链路逐跳可追溯
- **WHEN** 任务的字段经过多个处理节点后写入目标
- **THEN** 系统保存每一步的字段来源与去向，血缘视图可沿链路回溯到原始源字段

#### Scenario: 多源合并血缘
- **WHEN** 目标字段来自合并节点且该节点有多个上游源
- **THEN** 系统记录该字段的全部上游来源，血缘视图中体现多对一关系

#### Scenario: 旧配置等价血缘
- **WHEN** 任务为仅含字段规则的既有配置
- **THEN** 系统按等价编译后的三节点流水线推导血缘，结果与原字段级血缘一致
