## 1. 前端字段转换删除交互改造 [P1]

- [x] 1.1 移除 `Tasks.jsx`「字段转换」标题行上的「删除规则」按钮，保留「添加规则」[P1]
  - 验证：打开新建/编辑任务表单，「字段转换」标题行仅剩「添加规则」按钮，不再出现「删除规则」按钮。

- [x] 1.2 在每条字段规则行行尾（源字段、规则类型、目标字段及其条件输入之后）新增「删除」按钮，点击后按索引删除该条规则（`setFields(fs => fs.filter((_, j) => j !== i))`）[P1]
  - 验证：配置多条规则后点击中间某条的「删除」，仅该条被移除，其余规则的源字段/目标字段/规则类型保持不变；删除最后一条后展示「未配置字段映射」空态提示。

## 验收补充

- 上述改动仅涉及前端，需通过 `vite build` 并回归任务保存流程，确认 `fields` 结构、表达式白名单校验与保存链路不受影响。
